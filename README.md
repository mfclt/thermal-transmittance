# CLT層構成別 熱貫流率（U値）理論値シミュレーター

CLT（直交集成板）の **奇数層（強軸）** と **偶数層（弱軸）** それぞれの開口率（ボイド率）[%] を入力することで、線形予測式から各層の熱伝導率 $\lambda$ および熱貫流率 $U$値（理論値）をリアルタイムに算出・比較できるWebアプリです。

## 主な機能
- **5層構成（150mm）・7層構成（210mm）のワンクリック切替**
  - 強軸（奇数層：最外層・内層）と弱軸（偶数層）の開口率を個別に入力可能
- **CLT断面ビジュアルプレビュー（SVG）**
  - 選択した候補の層構成・開口率・熱伝導率 $\lambda$ を断面図でリアルタイム可視化
- **前提条件のカスタマイズ対応**
  - 線形予測の傾き $a$・切片 $b$、表面熱伝達抵抗 $R_i, R_o$、ラミナ1層厚さ $d$ を画面上で変更可能
- **代表パターン一括読込 ＆ CSV出力**
  - Excel出力に対応したBOM付きUTF-8 CSVエクスポート機能、入力内容のブラウザ自動保存
- **PWA対応（iOS / Chrome アプリ化・オフライン動作）**
  - iPhone / iPad のホーム画面や PC / Android の Chrome に専用アイコン付きアプリとしてインストール可能

## GitHub Pages での公開手順（ブラウザだけで完結）

1. **GitHubで新規リポジトリを作成**
   - GitHub にログインし、右上の `+` → **New repository** をクリックします。
   - Repository name（例: `clt-uvalue-simulator`）を入力し、**Public** を選択して **Create repository** を押します。
2. **ファイルをアップロード**
   - 作成されたリポジトリ画面の **uploading an existing file** をクリックします。
   - 解凍したフォルダの中身（`index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `favicon.ico`, `icons/` フォルダ一式）をすべてドラッグ＆ドロップし、**Commit changes** を押します。
   - ※ `index.html` がリポジトリの直下（ルート）に配置されるようにしてください。
3. **GitHub Pages を有効化**
   - リポジトリ上部の **Settings** タブ → 左メニューの **Pages** を開きます。
   - **Branch** の欄で `main`（または `master`）と `/ (root)` を選択し、**Save** をクリックします。
   - 1〜2分ほど待つとページ上部に公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が表示されます。

## スマホ・PCでのアプリ化（アイコン追加）手順

### iPhone / iPad（Safari）
1. 公開URLを **Safari** で開きます。
2. 画面下部の **共有ボタン（四角に上矢印）** をタップします。
3. **「ホーム画面に追加」** を選択すると、CLT断面アイコン付きのアプリとしてホーム画面に追加されます。

### Android / PC（Google Chrome）
1. 公開URLを **Google Chrome** で開きます。
2. アドレスバー右端の **インストールアイコン**、またはメニュー（`⋮`）内の **「アプリをインストール」／「ホーム画面に追加」** をクリックします。
